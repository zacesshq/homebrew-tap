# Zacess Homebrew tap

Formulae for the Zacess terminal programs. Install with:

```sh
brew install zacesshq/tap/zacess-profile
brew install zacesshq/tap/zacess-scenes
brew install zacesshq/tap/zacess-games
```

Each formula installs the built binary for the machine from the matching GitHub release and checks it against the recorded checksum. The formulae are filled from [zacesshq/profile](https://github.com/zacesshq/profile), [zacesshq/scenes](https://github.com/zacesshq/scenes) and [zacesshq/games](https://github.com/zacesshq/games) at each release.
