# Zacess Homebrew tap

Formulae for the Zacess terminal programs. Install with:

```sh
brew install zacesshq/tap/zacess-scenes
brew install zacesshq/tap/zacess-games
brew install zacesshq/tap/zacess-profile
```

Each formula installs the built binary for the machine from the matching GitHub release and checks it against the recorded checksum. The formulae are filled from [zacesshq/scenes](https://github.com/zacesshq/scenes), [zacesshq/games](https://github.com/zacesshq/games) and [zacesshq/profile](https://github.com/zacesshq/profile) at each release.
